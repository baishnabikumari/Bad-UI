## Controls

- **Arrow keys / A, D** - move the claw.
- **Space / Enter / Down arrow key** - drop the claw, grab a ball, or release a ball.
- **On-secreen button** - same controls, touch-friendly.

## what it do
- 14 tuned bars across pit, each plays a note
- 5 ball types.
- **SIN,TRI,SAW,SQR** - detuned oscillator layers through a moving filter.
- Drop velocity controls volumne
- scale picker - major, minor, chromatic, changes the bar tuning live
- Bounce picker - low, medium, high and super can be control using the button.
- web MIDI input
- pit slowly refills over time so you never runs out of the notes.

**Each and every sound is generated with the Web API - no audio files or real beats**
